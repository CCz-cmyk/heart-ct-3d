解剖模型 · Anatomical Model

加载 73.3 MB 的 heart_model.glb，150 万三角面承载心脏本体、冠状动脉与肺血管树，外加三张贴图。页面载入即自动居中、等比缩放至视口。

  • 自由视角：拖拽旋转 / 滚轮缩放，双击复位
  • 病例专属模型：探测 case_01.glb，命中即自动替换，无需改代码
  • 病灶投影：22 处病灶按解剖位置打黄球，与 MPR 口径一致

体数据渲染 · Volume Rendering

VTK.js 直接吃 256×256×192 的 float32 HU 体数据做体绘制，配合窗宽窗位与三方向剖切，观察心肌密度与病灶边界。

  • 窗宽窗位：默认 600 / 120，实时重采样
  • 三方向剖切：轴位 Z / 冠状 Y / 矢状 X 三滑块联动
  • 一键重置：相机与切面回到标准初始位

四个阶段，把数字变成结论

提示词里的每一个数字都来自实测 HU 统计，不是让模型「猜」。结果经规则校验后才落到报告卡上，越界参数会被修正并留痕。

01

读取体数据 stage · volume

定位病灶所在体素，取球内区域做 float32 HU 采样，同时读取层厚与像素间距。

02

实测 HU 特征 stage · feature

统计球内 均值 / 中位数 / P90 / P95 / 峰值 / 最小 / SD，再取背景环（r+2～r+9）算均值 ± SD 与 ±3SD —— 这组数据是提示词的唯一事实来源。

03

大模型推理 stage · llm

逐病灶单独请求，返回结构化 JSON：类型、重度、阈值、层厚、置信度、所见、建议。前端同步显示阶段、进度、已用秒数与 tokens 用量。

04

结果校验 stage · verify

高密度灶阈值须落在 [背景均值+3SD, 峰值×90%]，低密度灶方向相反；直径 ≤30 mm 的灶层厚一律夹到 1 层。越界即修正留痕，漏字段按规则兜底。
